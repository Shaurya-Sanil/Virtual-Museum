# Virtual Museum with AI Tour Guide

## 📜 Overview
The **Virtual Museum** is an interactive AI-powered experience where users can explore different themed museum rooms, including the **Library, Research Room, and Cultural Floor**. The project features an AI **ChatGPT-based tour guide**, which assists visitors by answering questions, providing artifact details, and even navigating them through different rooms.

## 🚀 Features
- **AI Tour Guide** powered by ChatGPT
- **Voice Interaction** using TTS for realistic speech responses
- **Dynamic Room Navigation** via buttons or AI commands
- **3D Artifact Viewer** with PyQt5 & Sketchfab integration
- **Immersive UI** with smooth transitions and elegant design
- **Background Ambient Music & Sound Effects** for realism
- **Future Scope:** AR/VR integration, interactive quizzes, and user authentication

## 🛠️ Tech Stack
- **Python (Tkinter)** - GUI development
- **OpenAI API** - AI-powered chatbot
- **gTTS** - Text-to-speech responses
- **PyQt5 & Sketchfab** - 3D model integration
- **Pillow** - Image handling

## 🎮 Getting Started
1. **Clone the Repository**
   ```sh
   git clone https://github.com/yourusername/virtual-museum.git
   cd virtual-museum
   ```
2. **Install Dependencies**
   ```sh
   pip install -r requirements.txt
   ```
3. **Run the Virtual Museum**
   ```sh
   python main.py
   ```
